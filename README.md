I'm a front-end engineer at [Loopscape](https://loopscape.com.br), where since 2023 I've been building ERPs and multi-tenant platforms with React and Next.js. On the side, I build open source tools for problems I keep running into.

- [Deskline](https://github.com/luannzin/deskline): remote desktop with no server to run. Paste a code, they accept, you see and control their screen.
- [Sightline](https://sightline-self.vercel.app): share your screen as a link, watched live in the browser with sound.
- [PartyLine](https://github.com/luannzin/partyline): a party game show in your terminal. Friends join over LAN or the internet, with no server.
- [LanPet](https://github.com/luannzin/lanpet): a pixel pet that lives on your desktop and meets your coworkers' pets over the LAN.
- [echo](https://useecho.dev): the note taker that learns with you.
- [better-intl](https://github.com/luannzin/better-intl): typed, file-based i18n for Next.js.
